# 知识点分类清洗计划

## 问题总结

调查发现三个核心问题：

### 1. "倍增" 错误归类到基础/其他
`oi-binary-lifting` 目前挂在 `sub-基础-其他` 下，但倍增是图论/数据结构核心技巧，不应在基础分类。

### 2. "搜索" 分类空壳
搜索分类（`cat-搜索`）下 0 个节点，所有搜索算法（BFS、A*、回溯、IDA*、双向搜索等）都在 `cat-基础` 下。

### 3. "其他" 子分类过乱
| 子分类 | 节点数 | 问题 |
|--------|--------|------|
| sub-基础-其他 | 1 | 仅含"倍增"，移走后可删除 |
| sub-图论-其他 | 29 | 大量可归入"树论""图基础"或新建子分类 |
| sub-数据结构-其他 | 20 | 多项可归入"树结构""高级结构""分块与离线" |
| sub-数学-其他 | 70+ | 最严重，可拆为"数论进阶""概率与统计""代数与数系" |
| sub-字符串-其他 | 5 | 可全部归入已有子分类，删除 |
| sub-杂项-其他 | 1 | 仅含 CDQ 分治，移至数据结构/分块与离线 |

---

## 方案

### Phase 1: 移动倍增 + 删空壳"其他"

**数据库迁移脚本** `backend/scripts/migrate_subtags.py`：

1. 移动 `oi-binary-lifting` → `sub-图论-树论`（"倍增"已是树论关键词）
2. 删除 `sub-基础-其他`（移走后为空）

### Phase 2: 清洗图论"其他"（29 项）

**新建子分类**：
- **特殊图论**：圆方树、弦图、支配树、斯坦纳树、图的着色、最大团搜索、最小树形图、平面图、拆点、Stoer–Wagner
- **图论计数**：矩阵树定理、LGV 引理、环计数问题、图上随机游走

**归入已有子分类**：
- → 树论：树基础、树的中心、树的直径、树哈希、树上随机游走、Prüfer 序列、AHU 算法、树上启发式合并
- → 图基础：图的存储、图论相关概念、有向无环图、点/边连通度
- → 最短路：k 短路、最小环
- → 基础算法（基础/基础算法）：差分

### Phase 3: 清洗数据结构"其他"（20 项）

**归入已有子分类**：
- → 树结构：AA 树、猫树、霍夫曼树、SBT、WBLT、手指树、左偏树、替罪羊树
- → 高级结构：LCT、Top Tree、ETT、析合树、划分树、PQ 树
- → 分块与离线：Sqrt Tree、区间最值操作（SegBeats）、CDQ 分治（从杂项移入）
- → 基础数据结构：哈希表、ST 表

### Phase 4: 清洗数学"其他"（70+ 项）

**新建子分类**：
- **数论进阶**：裴蜀定理、同余方程、连分数、离散对数、筛法（杜教/Meissel-Lehmer/Min_25/Powerful Number/洲阁）、类欧几里德、阶乘取模、升幂引理、线性同余方程、卢卡斯定理、模算术、Pell 方程、分解质因数、阶 & 原根、二次域、二次剩余、高次剩余、Stern–Brocot、狄利克雷卷积
- **概率与统计**：概率基本概念、概率不等式、条件概率与独立性、随机变量、随机变量的数字特征
- **代数与数系**：群论、环论、域论、布尔代数、序理论、复数、弧度制与坐标系、进位制、格雷码、平衡三进制、数字系统、线性规划、单纯形、拟阵、高精度、位操作、二进制集合、插值、Schreier–Sims、Berlekamp–Massey、零和游戏

**归入已有子分类**：
- → 组合数学：伯努利数、Entringer Number、Eulerian Number、斐波那契数列、图论计数、分拆数、Pólya 计数
- → 线性代数：对角化、初等变换、Jordan 标准型、线性映射、内积和外积、向量、线性空间
- → 多项式：形式幂级数复合、Chirp Z 变换、指数生成函数、FFT、代数基本定理、FWT、常系数齐次线性递推、NTT、OGF、符号化方法
- → 数论基础：最大公约数（gcd 已在关键词中）

### Phase 5: 清洗字符串"其他"（5 项）

**归入已有子分类**：
- → 字符串匹配：Boyer–Moore、Lyndon 分解、最小表示法
- → 字符串基础：标准库
- → 回文与数组：后缀平衡树

**删除** `sub-字符串-其他`（归完后为空）

### Phase 6: 清洗杂项"其他"（1 项）

- CDQ 分治 → 数据结构/分块与离线
- 删除 `sub-杂项-其他`

### Phase 7: 更新 SUBTAGS 配置

在 `backend/scripts/seed_knowledge_graph.py` 中：

1. 新增子分类定义：
   - 图论 → "特殊图论"、"图论计数"
   - 数学 → "数论进阶"、"概率与统计"、"代数与数系"
   - "基础" 分类 → 新增 SUBTAGS 条目（基础算法、搜索）

2. 扩展现有关键词覆盖，减少"其他"落点

### Phase 8: 更新 MERGE_MAP

`backend/scripts/merge_duplicate_kps.py`：
- 更新 CF 标签合并目标，指向新建的子分类
